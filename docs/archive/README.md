# docs/archive — historical build record

These are **historical** per-phase artifacts, preserved for provenance. They reflect
the state of the project at the time they were written and are **not** current
references. For the live picture use, in order:

- `../CURRENT_STATE.md` — the honest current-state inventory (read this first).
- `../../CLAUDE.md` — current-state DNA + active rules.
- `../../CHANGELOG.md` — build-time decisions and per-phase outcomes (the _why_).
- `../../BLOCKERS.md` — open carry-forward items.

## What's here

- **Phase handoffs** (`PHASE_2_HANDOFF.md` … `PHASE_9.5_*`, plus `PHASE_0_HANDOFF.md`) —
  each phase's release deliverable: what shipped, autonomous decisions, issues carried
  forward, verification snapshot. (The latest handoff, `../PHASE_10_HANDOFF.md`, stays at
  `docs/` top until a successor supersedes it.)
- **Phase 8 audit suite** — `PHASE_8_BUG_CATALOG`, `PHASE_8_COVERAGE_AND_DOCS_AUDIT`,
  `PHASE_8_GATE_VERIFICATION`, `PHASE_8_PERF_BASELINE`, `PHASE_8_PLUGIN_AUDIT`,
  `PHASE_8_RUST_AUDIT`, `PHASE_8_SIDECAR_AUDIT`, `PHASE_8_VISUAL_REGRESSION_REPORT`,
  `PHASE_8.1_CI_REPAIR`.
- **Phase 9 / 9.5** — `PHASE_9_BUG_CATALOG`, `PHASE_9_TEST_PLAN`, `PHASE_9.5_BUG_CATALOG`,
  `PHASE_9.5_MAC_RUNNER`, `PHASE_9.5_MORNING_REPORT`, `PHASE_9.5_REAUDIT_SPEC`.
- **Per-teammate blocker logs** — `BLOCKERS-I.md`, `BLOCKERS-M.md`, `BLOCKERS-N.md`
  (superseded by the consolidated `../../BLOCKERS.md`).

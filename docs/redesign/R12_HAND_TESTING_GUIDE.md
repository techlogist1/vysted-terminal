# Hand-Testing Guide (R12) — retired

This guide described the product as it stood at R12 and no longer matches it, so
its walkthrough has been removed rather than left to mislead.

For someone coming back to the app cold, use the hand-testing guide in the
release docs bundle, written from the 0.9.0 release candidate and promoted
alongside the release notes at the launch tag. The current baseline of what
exists is `docs/CURRENT_STATE.md`.

# 0.10.1 backlog

## 1. What this is

The R16 findings that did not block 0.10.0: the final review's unverified mediums and lows, and the items the lead filed while building. Every critical and high from the final review (`docs/redesign/verification/r16/local/final-review.json`, review run `wf_2d30ccd9-766`) was fixed before the tag, in the fix round `wf_643d56d8-85e`. The 0.9.1 backlog (`BACKLOG_0.9.1.md`) is still open alongside this one.

## 3. Filed by the lead during R16

| Severity | Problem                                                                                                                                                                                                                               | Fix shape                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| medium   | `/llm/keys/validate` and `/llm/chat` take the API key in the JSON body, not a header. This is loopback only and never logged, but it breaks the header-only BYOK rule.                                                                | Move the key to an `X-…-Key` header in both routes and the renderer. Keep the router no-echo tests.                  |
| medium   | A paused model download auto-resumes on relaunch and activates `local`, even after the user switched to their own key.                                                                                                                | Auto-resume only when the provider is still `local` or unset. Never auto-activate over a configured key.             |
| low      | Cancelling a download discards it without asking, and Pause and Cancel behave the same.                                                                                                                                               | Pause keeps the `.part` file. Cancel asks before discarding.                                                         |
| low      | The Settings Models page overlaps the Research "hardware" group at narrow widths.                                                                                                                                                     | Layout fix in `ModelsSection`.                                                                                       |
| low      | Under the under-8gb tier (16k context), five large tool results in parallel still overflow the context. The wizard steers that tier toward "My own API key".                                                                          | Cap the number of parallel tool results per round by the context budget, or summarise results before replaying them. |
| low      | `VYSTED_UPDATER_ENDPOINT` is honoured in release builds (`http://127.0.0.1:` or `https://` only; the signature check still applies).                                                                                                  | Document it in `docs/SAFETY_ARCHITECTURE.md`, or gate it to debug builds.                                            |
| low      | The "On this computer" step labels Qwen 3.5 4B "Runs well here" (total RAM) and, in the same view, warns "This computer is short on free memory for Qwen 3.5 4B" (RAM free right now). Seen on a 16 GB Mac in the R16 GUI round (F2). | Word the notice as momentary ("Right now, other apps are using most of the memory…"), or fold it into the fit label. |
| info     | Unsigned updates change the app's ad-hoc code signature, so after each update macOS asks for the login password once per saved keychain item. This is documented for users ("Always Allow").                                          | Goes away with code signing, which is out of scope until the operator enrols.                                        |

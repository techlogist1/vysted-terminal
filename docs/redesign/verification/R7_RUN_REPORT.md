The agent narrates in prose first; step traces and timings collapse behind one tertiary disclosure line, and the missing-paragraph-break bug ("look.Set") is regression-tested. "Open the chart and settings side by side" now produces a real split: the layout engine used to refuse to move already-open panels while the agent claimed success; it now moves them, verified live (one group became two). Dead wiring is gone: the command-palette agent rows actually switch the persona, and typing "Route Mobile" finds ROUTE both in the watchlist input and in a new live-ticker palette group. The Greeks dashboard, Settings (sectioned, with a jump nav), equity overview, marketplace, and the quant pricers were redesigned to the design law, and the node editor's white zoom controls — the canonical "design system not enforced" defect — render on the ladder now.

Underneath, the research engine has the three search tiers the plan called for. Tier 1 is keyless multi-engine rotation (DuckDuckGo, Brave, Mojeek) with per-engine circuit breakers, pacing, curl_cffi browser impersonation, full-page extraction, and prompt-injection scrubbing — I ran a live query through the shipped backend and got eight real results with zero keys, and `GET /search/status` reports each engine's honest cooldown state. Tier 2 is the one-click managed SearXNG: against this Mac's real Docker daemon, the state machine went not-set-up → pulling → starting → ready in fifteen seconds and the instance served ten real results for a Reliance query — setup is genuinely the app's job now. Tier 3 is the BYOK hosted tier (OpenRouter's current web-search server tool with Firecrawl default and Exa optional, verified against the live OpenRouter docs, plus the Perplexity sonar one-call lane; Tongyi-DeepResearch is delisted from OpenRouter — verified live — and stays out of the picker). The depth slider maps Normal/Deep/Ultra onto the fast/iterative/heavy loops with scaled coverage strictness and finance tuning: exchange-and-regulator-first source ranking, recency threading, an Ultra cross-check round, and a coverage floor that accepts web-only evidence for instruments with no price feed.

India data is exchange-direct. The BSE scrip master is real now (4,873 rows including SME boards, integrity-tested row by row), the bhavcopy provider routes by scrip code, and a new NSE-direct provider does the cookie dance with anti-bot defenses, built from observed live response shapes. Corporate announcements, results calendars, and shareholding patterns are ingested from both exchanges, served under `/disclosures/*`, and exposed to the agent as tools.

Hackability is first-class: a sandboxed code node in the node editor (with a server-side parity evaluator so agent-authored workflows run too, and a new `save_workflow` MCP tool so the agent can author them), a declarative backtest DSL that executes server-side — I ran a momentum strategy (`sma(20) > sma(50)` entry, `rsi(14) > 70` exit) on real RELIANCE data and got five real trades with full metrics — and the screener formula layer with caret-positioned validation errors that I verified rejects injection attempts at the grammar.

## Adjacent findings (new, not refutations)

1. **near R15-RESEARCH-025 (medium)**: a boolean operand of a comparison is still silently coerced. `(pe_ratio > 3) > 0.5`, `(pe_ratio < 15) >= 1`, `roe > (pe_ratio < 15)` and `(pe_ratio < 15) == 1` all validate ok:true on POST /screener/formula/validate. In-process, `roe > (pe_ratio < 15)` matches roe 0.9 / pe 99 (0.9 > 0.0) and misses roe 0.9 / pe 3 (0.9 > 1.0): a meaningless screen. The cause is that `_Parser._comparison` discards `_right_is_bool` and ignores `left_is_bool`, and the TS twin `comparison()` does the same.
2. **near R15-UI-028 (medium)**: the agent/MCP `compute_greeks` and `price_option` tools return QuantLib units with no unit label or conversion (`quant_tools.py` returns `result.model_dump()`). Asked for vega and theta of the entry's default call, llama3.1:8b answered "vega … approximately 83.47 and the theta is approximately -16.33" (`shard-5-raw/ag-greeks.sse`). The desk-convention values are 0.835 per vol point and -0.0447 per day.
3. **near R15-UI-032 (low)**: `search_companies` does a raw lowercase substring match. "Coca-Cola" misses KO (SEC title "COCA COLA CO") and returns only CCEP and COKE. "Apple" returns MAUI LAND & PINEAPPLE (via "pineapple").
4. **near R15-AGENT-084 (low)**: `parseChartDrawing` falls back to the open chart only when `panelId` is empty. The 8b model sent `panelId: "chart panel ID (assuming it is already open)"`, which bypasses the fallback and resolves to `problem: "no chart is open"`, while the sidecar reported the action staged and the model told the user "I have added a horizontal line". Source: `shard-5-raw/ag-draw-tcs.sse`; the frontend outcome was read from code, since the GUI was not run.
5. **near R15-DOCS-005 (low)**: BLUEPRINT.md:20 and :615 say "12 AI agents". Live `/agents` and `sidecar/agents/*.json` have 13 first-party agents, and CURRENT_STATE says 13.

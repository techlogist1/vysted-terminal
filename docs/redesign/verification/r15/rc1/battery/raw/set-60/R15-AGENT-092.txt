=== confirmed mechanism (run_manager.py:180-206, 302-306) ===
`undispatched` dict holds a staged host action keyed by tool_call_id; it only
moves into `host_actions` inside `_on_tool_result` (i.e. once the tool
actually got a result back). A budget breach sets `halted`/`breach_reason`
BEFORE that tool result arrives, so the action never leaves `undispatched` and
`_output()`'s `host_actions` list stays empty on the error path. Line 182-183
comment explicitly cites "R15-AGENT-092" as the reason for this design.
This reproduces the cert's live result (host_actions: [] on breach) by source,
without needing a live budget-breach run through the Ollama lock.

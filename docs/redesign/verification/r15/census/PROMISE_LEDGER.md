# R15 Promise Ledger

Assembled from all 23 intent-verification chunk ledgers under `census/intent/ledger-*.json` (819 raw promise ids -> 1,003 verified rows after Gate 2 register + session-2 fills). Cross-referenced against `census/raw/intent-*.json` (raw findings) and `census/refute/intent-*.json` (refute verdicts) where a link could be established.

Scope note: per operator decision 23 Sep 2026 (D81, `docs/redesign/DECISIONS.md`), trading (broker order execution, order placement/review, live/paper switching, the broker plugin, Tradesa V2) is **removed from the product**. Every promise on that surface is ledgered `dropped`, not `missing`/`partial` -- this is an operator decision, never a defect. The user's own tracked portfolio (manual holdings, cost bases, P&L, CSV export, notes, watchlists) stays in scope and is graded normally.

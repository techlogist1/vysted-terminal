Scope note: per operator decision 23 Sep 2026 (D81, `docs/redesign/DECISIONS.md:141`), trading
(broker connectivity, order placement, order proposal/review, simulated paper brokerage,
live/paper mode switch, the broker plugin, live-trading roadmap items) is **removed from the
product, permanently**. Every promise whose subject is broker order execution, order
safeguards, paper brokerage, or live mode is ledgered `dropped`, never `missing`/`partial` —
this is an operator decision, never a defect. The user's own tracked portfolio (manual
holdings, cost bases, P&L on real prices, CSV export, notes, watchlists) and everything the
agent does with it stays in scope and is graded normally.

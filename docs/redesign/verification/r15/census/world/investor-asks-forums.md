# R15 Census — World sweep: what serious Indian investors ask for and cannot get

**Sweep:** `WORLD-ASK` (world research, investor demand-side)
**Date of research:** 2026-09-19
**Model:** `claude-opus-5[1m]`
**Method:** live web (WebSearch + WebFetch). Every claim carries a URL and a verbatim quote or a
concretely described observation, with a date where the source shows one. Fetch failures are
labelled inline and downgraded to search-snippet evidence, honestly marked.
**Scope note:** live broker ORDER EXECUTION is deliberately out of this release (1.0 roadmap) —
nothing below counts it as a gap. Locked and not reopened: two-tier research, the R9 design
system, the dev keystore, the plugin system, Tradesa staying gone.

**Read-only:** no repo files were modified by this sweep other than this one.

## Fetch blocks / degradations encountered (labelled honestly)

- `forum.valuepickr.com/t/screener-in-…/1148/1536` — **WebFetch timeout (60s exceeded)** on first
  attempt. Where a ValuePickr page could not be fetched, the finding is sourced from the search
  engine's indexed snippet of that exact page and is marked `[snippet-only]`.
- `reddit.com` threads — Reddit blocks unauthenticated fetching of most comment pages. Reddit
  findings below are sourced from indexed snippets, the r/IndiaInvestments **wiki**
  (`indiainvestments.wiki`, which is fetchable and is the subreddit's own canonical guidance), and
  from third-party write-ups that quote the threads. Marked `[snippet-only]` or `[wiki]`.

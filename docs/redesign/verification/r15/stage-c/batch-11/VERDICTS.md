## Issues found (not in this batch's scope; for the backlog)
1. Option chain availability (above): cache today's probe outcome briefly, or treat a failed today-probe as "missing" when an older cached day exists.
2. Tool args: llama3.1:8b repeatedly sends integers as strings ('5', '10', '100' for max_strikes, limit and similar). The strict schema gate rejects them and the model then answers without data. This drove most of the ollama eval failures (sec-filings, sec-insider, disclosures, option_chain). Coercing numeric strings for integer params at the tool gate is a class fix.
3. The agent-eval grader passes a trial whose tool call returned an error, because tool results are not in the vy stream. The first option_chain run (expiry 'nearest' -> 422) grades [] against an ad-hoc expectation.
4. Upgrade backups (`backups/<old-build>/`) are never pruned. Each build change adds a full data-dir copy.
5. A `.BO` request for a dual-listed name is served by nse_direct (AMAL.BO returned NSE's 28 bars since its 2026-08-17 NSE listing, not BSE's longer history). This predates the batch.
